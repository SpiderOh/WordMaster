# E2E Smoke

启动 Docker Compose 或本地前后端后，用浏览器访问 `http://127.0.0.1:5173`，按以下顺序进行最小验收：

1. 上传 `data/reden_vocabulary_6550.csv` 并确认词库可见。
2. 打开学习页，点击单词显示释义，完成页面并确认下一页或无候选空状态。
3. 在遗忘入口筛选、勾选单词并完成专攻结果。
4. 在日期、统计和设置页确认数据可见且设置能保存。
5. 断开网络记录一次遗忘，恢复网络后确认待同步提示消失。

服务器模式先用 `.env` 提供用户名、密码和随机密钥，再通过登录页获取访问权限。不要把 `.env`、访问令牌或数据库文件加入版本库。
